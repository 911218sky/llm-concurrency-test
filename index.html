LLM Concurrency
Test

Fires N simultaneous requests and measures whether they run in parallel. Local mode automatically relays API calls through this machine to avoid browser CORS failures.

Your API key stays in this browser. On the local deployment, requests go through the local relay automatically, so providers do not need browser CORS support. Fill in the API key and endpoint, then leave the field to load available models automatically.
⚠️
Requests blocked by CORS?
If your API provider doesn't allow browser-origin requests, install the LLM Concurrency Test - Relay Chrome extension and reload this page. It relays your requests through a background service worker so the browser's same-origin policy no longer applies.
